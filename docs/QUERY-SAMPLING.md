# Query 采样说明

P1.1 的采样默认关闭。只有用户在设置中明确打开「允许发送脱敏搜索样本」，并填写自托管接收端后，插件才会按设置的比例发送成功的 AI / 本地语义搜索样本。接收端必须使用 HTTPS；开发时可使用 `localhost` 的 HTTP 地址。

每条样本只包含：

- 查询形状：长度分桶、字符类别、词数、已识别的 33 类意图 key、否定意图 key、未知正向/否定词数量、是否纯否定；
- 排序指标：候选数、结果数、是否降级、前 10 名是否命中关键词/向量/标题召回、四舍五入后的 RRF/重排分数，以及命中词/短语/意图/否定的数量；
- 日期、模式（AI 或 local）和可选的客户端版本。

请求体不包含原始 query，也不包含插件 ID、名称、标题、描述、README 或其它插件全文。未知词只记录数量，因此接收端可以发现「未覆盖意图/否定表达」的比例，但不能从样本还原这些词。网络失败和服务端错误会被静默吸收，不影响搜索结果。

## 发布前检查

1. 明确接收端的运营者、保留期限和访问控制，并在设置文案或隐私说明中告知用户。
2. 确认目标目录政策允许这种显式 opt-in 的客户端数据发送；若不允许，保持开关关闭并改用本地导出方案。
3. 用 `src/domain/search/query-sampling.test.ts` 验证 payload 不含原始 query 或插件识别信息。
